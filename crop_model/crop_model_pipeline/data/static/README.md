# Factual crop-model static inputs

Supply the following files locally:

- `monthy_climate_original_yields.csv`: historical training table used by `scripts/main.py` (the spelling `monthy` is retained for compatibility);
- `voivodeships.shp` and its sidecar files: provincial boundaries with a `nazwa` attribute.

Record provenance, licence, schema, temporal coverage, units, and checksums. These files are ignored by Git.
